# 📖 ProDev Backend Engineering program (My Journey)
## Overview

The ProDev Backend Engineering program is designed to equip aspiring software engineers with the skills and knowledge needed to excel in backend development. This program covers a wide range of topics, including server-side programming, database design and management, API development, CI/CD pipelines with Jenkins, containerization with Docker and container orchestration with Kubernetes, Django ORM, and Django Rest Framework: including security, IP tracking and throttling, GraphQL, shell scripting, Git flows, server management (load balancing, firewalls, etc.), and deployment, task automation with Redis and RabbitMQ, Webstack monitoring and logging.

Participants will engage in hands-on projects, collaborate with fellow peers, and gain practical experience using modern tools and technologies. By the end of the program, graduates will be well-prepared to tackle real-world challenges and contribute to the success of their organizations.

## 🚀 Program Structure

The program is divided into several modules, each focusing on a specific aspect of backend development. Participants will progress through the following stages:

1. **Week 0: Pledge, Map Your Journey, What You Will Learn, Backend Blueprint**
At the start of the program, I made a pledge to commit to my learning journey. I also mapped out my individual learning paths and understood the key concepts which I mastered throughout the program.

By the end of Week 0, I had a clear understanding of the program's objectives and how to navigate my learning experience effectively.

The backend blueprint provides a comprehensive overview of the backend development landscape, including the technologies and tools that will be covered in the program.

2. **Week 1: AI prompting, Be Visible, DataScape, Blueprint: Requirement Analysis**
In Week 1, I delved into the world of AI prompting and learned how to effectively communicate with AI models. I also explored the importance of visibility by building a personal brand and showcasing my skills to potential employers using platforms like LinkedIn, GitHub, and personal blogs.

I also mastered the database design concepts by designing ERDs and understanding the principles of normalization. This foundational knowledge is crucial for creating efficient and scalable databases.

Additionally, I studied the Blueprint for Requirement Analysis, which equipped me with the skills to gather and document project requirements effectively.
